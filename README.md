# Rachida El Hady Portfolio

My personal portfolio showcasing frontend, mobile, and creative development projects.

## Built With

- Nuxt 4
- Vue 3
- TypeScript
- SCSS
- GSAP
- Three.js

## Local Development

Copy `.env.example` to `.env`, then run:

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
