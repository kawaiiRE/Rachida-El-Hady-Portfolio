# Auraflow portfolio captures

The logo is extracted from the 256px PNG entry in `Wallpaper/public/favicon.ico`.

The background and six previews were captured from the public Auraflow studio at
`https://auraflow.rachida.dev/fluid` in a 1440 × 900 browser viewport on
2026-09-06. Each mode was seeded and drawn on before capture so the gallery shows
real Fluid Ink, Ink Marbling, Reaction Bloom, Neon Silk, Aurora Field, and Nebula
Forge output from the updated renderer.
